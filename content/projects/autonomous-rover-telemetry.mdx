## Overview

The Autonomous Rover Telemetry project couples custom microcontroller firmware with an onboard sensor array to navigate constrained environments and broadcast metrics over low-power wireless links.

## Technical Highlights

- **Dual-MCU Architecture**: Segregates real-time motor control loops on an STM32 from high-level Wi-Fi/Bluetooth telemetry on an ESP32.
- **WebSocket Telemetry Stream**: Broadcasts IMU and LiDAR rangefinder measurements to an operator station at 60 Hz.
